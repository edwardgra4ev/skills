# Skills

Набор навыков для работы с задачами проекта в AI-агентах.
Инструкции навыков хранятся в `skills/<категория>/`; каждый каталог можно
установить отдельно вместе с его вспомогательными файлами.

```text
skills/
  engineering/
    feature-trace/
      SKILL.md
  productivity/
    project-todo/
      SKILL.md
      references/workflow.md
      agents/openai.yaml
README.md
```

`skills/` содержит исходники распространяемых навыков. `.agents/skills/`
в целевом проекте — место их установки. Вложенный `agents/openai.yaml`
содержит метаданные интерфейса конкретного навыка.

## Навыки

| Навык | Назначение |
|---|---|
| [feature-trace](skills/engineering/feature-trace/SKILL.md) | Проследить функцию от входа до результата, объяснить данные, состояния, сбои и диагностику; оценить влияние изменения контракта. |
| [project-todo](skills/productivity/project-todo/SKILL.md) | Создать или прочитать TODO проекта, интерактивно добавить или выбрать задачу, подготовить ТЗ и план либо перейти к реализации по готовым требованиям. |

## Установка

Скачайте набор или клонируйте этот репозиторий. Скопируйте каталог нужного
навыка (`skills/productivity/project-todo` или `skills/engineering/feature-trace`)
целиком в `.agents/skills/` целевого проекта.
При наличии одноимённого навыка сначала сравните версии.

Для другой среды используйте её каталог установки навыков, сохраняя
`SKILL.md` и имеющиеся вспомогательные файлы внутри каталога навыка.
Рабочим каталогом агента должен быть целевой проект.

## Использование

Вызовите `$feature-trace`, чтобы разобрать конкретный механизм, например:

```text
Используй $feature-trace: проследи обработку заказа от HTTP-запроса до уведомления.
Используй $feature-trace: найди потребителей события и оцени изменение его схемы.
```

Навык работает по исходникам проекта без обязательных внешних зависимостей.
Использует CodeGraph для уже индексированных репозиториев и Serena для
навигации по символам и ссылкам, если инструменты доступны; иначе — поиск по исходникам.

Вызовите `$project-todo` или попросите агента использовать навык по имени.

- Если TODO отсутствует, навык создаёт пустой реестр по правилам проекта
  или по пути `docs/tasks/TODO.md`.
- Если реестр пуст, предлагает добавить задачу через интерактивный вопрос.
- После выбора задачи предлагает подготовку ТЗ через grill-me / grill-with-docs
  либо разработку по существующему ТЗ.
- Явный запрос только списка завершается после показа списка.

Примеры:

```text
Используй $project-todo: покажи незавершённые задачи.
Используй $project-todo: сформируй ТЗ для TASK-001 через grill-me.
Используй $project-todo: начни разработку TASK-001 из docs/tasks/TODO.md.
```

## Зависимости

Для просмотра TODO и добавления записи внешние навыки не нужны.
Для интервью установите выбранный grill-навык и зависимости его версии
из [mattpocock/skills](https://github.com/mattpocock/skills).
Они распространяются отдельно и не включены в этот репозиторий.
Разработка по достаточному готовому ТЗ не требует grill.

## Документация и состав

- [Workflow](skills/productivity/project-todo/references/workflow.md).

Локальные задачи этого репозитория в `docs/tasks/` исключены из Git.
Задачи пользователей создаются в их рабочих проектах.

## Изменение набора

Для нового навыка создайте каталог `skills/<категория>/<имя>/` с `SKILL.md`,
содержащим YAML-поля `name` и `description`, и добавьте его в таблицу выше.
Вспомогательные документы храните рядом с навыком и связывайте относительными
ссылками. Проверяйте сценарии запуска после изменения инструкций.
