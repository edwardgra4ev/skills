# Skills

Набор переносимых навыков для AI-агентов: работа с задачами проекта
и исследование поведения кода.

- [feature-trace](docs/feature-trace.md) — проследить работу функции от входа до результата, разобраться в данных, сбоях и влиянии изменения контракта.
- [project-todo](docs/project-todo.md) — посмотреть и выбрать задачи проекта, подготовить ТЗ и план или начать разработку по готовым требованиям.

[Документация: каталог навыков, установка и использование](docs/index.md).

`skills/` содержит устанавливаемые инструкции для агентов и необходимые
им ресурсы. `docs/` содержит пользовательскую документацию.
