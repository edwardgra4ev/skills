# project-todo

Навык помогает работать с задачами проекта: посмотреть незавершённые,
выбрать задачу, подготовить требования и план или продолжить реализацию
по готовому ТЗ. Контекст сохраняется в документах целевого проекта,
чтобы работу можно было продолжить в другом чате.

## Подключение и зависимости

Следуйте [общей инструкции установки](index.md#установка), выбрав
`skills/productivity/project-todo/`. Копируйте каталог целиком, включая
`references/` и `agents/`.

Для просмотра TODO, добавления задачи и разработки по достаточному готовому
ТЗ внешние навыки не нужны. Для интервью нужен выбранный grill-навык:

- `grill-me` — уточнение требований, границ и плана.
- `grill-with-docs` — проработка с документированием предметной области,
  ADR и глоссария.

Эти навыки распространяются отдельно в [mattpocock/skills](https://github.com/mattpocock/skills).
Установите выбранный навык и зависимости его версии в среду агента.
`project-todo` сам их не устанавливает; при отсутствии зависимости сообщает об этом.

## Как использовать

Запустите агента в целевом проекте и вызовите `$project-todo` или попросите
использовать навык по имени.

```text
Используй $project-todo: покажи незавершённые задачи.
Используй $project-todo: помоги выбрать следующую задачу.
Используй $project-todo: добавь задачу экспорта отчёта в CSV.
Используй $project-todo: сформируй ТЗ для TASK-001 через grill-me.
Используй $project-todo: начни разработку TASK-001 из docs/tasks/TODO.md.
Используй $project-todo: продолжи TASK-001 по сохранённым требованиям и плану.
```

Замените ID и пути существующими данными проекта. Если действие и задача
указаны явно, повторно выбирать их не требуется.

## Что происходит после запуска

Агент находит реестр задач и сохраняет принятые в проекте пути, имена,
форматы и статусы. Если реестра нет, создаёт пустой по правилам проекта
или по пути `docs/tasks/TODO.md`. Это относится и к запросу только списка;
явный запрет пользователя на запись имеет приоритет.

При запросе только списка агент показывает задачи и завершает работу.
В остальных случаях пустой реестр приводит к предложению добавить первую
задачу, а непустой — к выбору задачи. Можно отказаться и завершить работу.

После выбора задачи доступны подготовка ТЗ через `grill-me` или
`grill-with-docs` и разработка по готовым требованиям. Выбор задачи сам по себе
не запускает реализацию. Подготовка ТЗ сохраняет решения и план; реализация
начинается по поручению пользователя. При недостаточных требованиях агент
предлагает уточнить их перед разработкой.

Вопросы задаются через доступную интерактивную форму, а при её отсутствии —
текстом. Отсутствие ответа не считается выбором.

## Где хранятся результаты

Задачи и документы создаются в целевом проекте, а не внутри установленного
навыка. Если в проекте нет собственных соглашений, используются:

| Документ | Путь по умолчанию |
|---|---|
| Реестр задач | `docs/tasks/TODO.md` |
| Требования | `docs/tasks/<slug>-requirements.md` |
| План | `docs/tasks/<slug>-plan.md` |

В существующем проекте агент продолжает имеющиеся документы. Контекст
продолжения содержит задачу, связанные пути, выбранный способ интервью,
текущий этап и открытые вопросы. После реализации агент фиксирует результаты
проверок и следующий шаг. Правила веток, публикации и обязательных проверок
берутся из целевого проекта.
