# Установка навыков

## Вручную через скрипт

Нужен Python 3.9 или новее. Сторонние Python-библиотеки не требуются.
Скачайте репозиторий архивом и распакуйте его либо клонируйте:

```sh
git clone https://github.com/edwardgra4ev/skills.git
cd skills
```

Все команды ниже выполняются из корня скачанного набора. На macOS и Linux,
если Python запускается командой `python3`, замените `python` на `python3`.
Пути с пробелами заключайте в кавычки.

### Интерактивная установка

Запустите скрипт без аргументов:

```sh
python scripts/install.py
```

Скрипт покажет нумерованный список навыков с описаниями из `SKILL.md`.
Вопросы и подсказки интерактивного меню отображаются на русском.
Введите номера или имена через
пробелы или запятые, например `1, 2` или `feature-trace project-todo`.
Введите `все` или `all`, чтобы установить весь набор.

Затем введите путь к существующему проекту. Пути с пробелами можно вводить
с кавычками или без них; относительный путь считается от текущего каталога
терминала, который скрипт покажет. После ввода корректного пути начнётся
установка в `<проект>/.agents/skills/`.

При неверном выборе или несуществующем пути скрипт предложит повторить ввод.
Для отмены на любом вопросе введите `отмена` или `q`, либо нажмите Ctrl+C. Пустой ввод
ничего не выбирает. Защита от перезаписи действует и в интерактивном режиме.

### Установка с параметрами

Для агента и автоматизации используйте параметры: этот режим не задаёт вопросов.

Посмотреть доступные навыки:

```sh
python scripts/install.py --list
```

Установить один навык в существующий проект:

```sh
python scripts/install.py --skill feature-trace --project "C:/work/my-project"
```

Установить несколько навыков или весь набор:

```sh
python scripts/install.py --skill feature-trace --skill project-todo --project "C:/work/my-project"
python scripts/install.py --all --project "C:/work/my-project"
```

Замените путь на каталог своего проекта, например `/home/user/my-project`
в Linux или `/Users/user/my-project` в macOS. Скрипт копирует каждый выбранный
навык целиком в `<проект>/.agents/skills/<имя>/`, включая `references/` и
`agents/`, если они есть. Документация, тесты и сам установщик не копируются.

Для среды с другим каталогом установки укажите его явно вместо `--project`:

```sh
python scripts/install.py --skill feature-trace --dest "/path/to/agent/skills"
```

`--dest` — сам каталог навыков, а не корень проекта. Относительные пути
считаются от текущего рабочего каталога терминала. Скрипт определяет расположение
исходников относительно своего файла, поэтому может запускаться из другого каталога.

## Повторная установка и обновление

Сначала получите новую версию набора, например через `git pull` в его локальной
копии. Установщик использует эти исходники и сам не скачивает обновления.
Идентичные установленные навыки пропускаются.

При отличиях скрипт показывает добавленные, удалённые и изменённые файлы.
Для текста в UTF-8 выводятся построчные различия: `-` означает установленное
содержимое, `+` — содержимое из набора. Для двоичных файлов показывается
факт изменения. Дополнительные локальные файлы тоже учитываются.

В интерактивном режиме скрипт предлагает заменить каждый отличающийся навык
с резервной копией. Введите `да`, чтобы согласиться. `нет`, пустой ввод или
`отмена` отменяют всю выбранную установку до изменения файлов. Все ответы
собираются до начала копирования.

При запуске с параметрами отличия по умолчанию приводят к остановке без записи.
После просмотра различий разрешите обновление явным флагом `--update`:

```sh
python scripts/install.py --skill feature-trace --project "C:/work/my-project" --update
```

`--update` заменяет все отличающиеся навыки из выбранного списка без вопросов
и устанавливает отсутствующие. Новая версия полностью заменяет каталог;
локальные правки и дополнительные файлы сохраняются только в резервной копии.

### Резервные копии и восстановление

Перед заменой старый каталог целиком переносится в уникальную резервную папку:

```text
<проект>/.agents/skills-backups/<имя>-<уникальный-суффикс>/<имя>/
```

Для `--dest` резервные копии находятся рядом с указанным каталогом, в
`<имя-каталога>-backups/`. Точный путь выводится перед заменой. Копии не
перезаписываются и не удаляются автоматически; они находятся вне каталога
навыков, чтобы агент не обнаруживал старые версии как действующие.

Для ручного восстановления перенесите текущий каталог навыка в другое место,
затем верните каталог `<имя>/` из нужной резервной папки на его прежнее место
в каталоге навыков. Если публикация новой версии завершается обычной ошибкой,
скрипт пытается сразу вернуть старую версию. После аварийного завершения процесса
или сбоя восстановления используйте напечатанный путь резервной копии.

Зависимости навыков установщик не скачивает;
они описаны на страницах [project-todo](project-todo.md#подключение-и-зависимости)
и [feature-trace](feature-trace.md#подключение).

При ошибке ввода-вывода установка может остановиться после уже скопированных
навыков. Повторный запуск пропустит готовые копии. Частично скопированный
навык не публикуется под его рабочим именем.

## Установка через агента

Передайте агенту следующий запрос, подставив проект и нужные навыки:

```text
Установи навыки feature-trace и project-todo из
https://github.com/edwardgra4ev/skills в проект <абсолютный путь к проекту>.

Прочитай docs/installation.md в репозитории. Скачай или клонируй набор
во временный каталог вне целевого проекта, либо используй уже имеющуюся
локальную копию, если я указал её путь. Проверь scripts/install.py перед запуском.
Запусти его через доступный Python с отдельным --skill для каждого навыка
и --project с указанным путём. Установи только перечисленные навыки.

При отличиях от установленной версии покажи различия и предложи обновление
с резервной копией; не перезаписывай локальные изменения без согласования.
После согласования повтори команду с --update и сообщи путь резервной копии.
Проверь, что содержимое установленных каталогов совпадает с исходниками,
включая вспомогательные файлы. Сообщи пути установки, результат проверки
и недостающие внешние зависимости. Не устанавливай зависимости автоматически.
```

Если набор уже скачан, вместо адреса репозитория можно указать его абсолютный
локальный путь. Для другой среды замените в запросе `--project` на `--dest`
и укажите точный каталог навыков. Агенту нужны доступ к исходникам, Python
и право записи в выбранный каталог; при ограничении доступа он сообщит об этом.

## После установки

Откройте целевой проект в своей среде агента и вызовите `$feature-trace`
или `$project-todo`, либо попросите использовать навык по имени.
Если среда не обнаруживает новые навыки сразу, обновите её список навыков
или начните новый сеанс согласно правилам этой среды.

Примеры рабочих запросов находятся на страницах
[feature-trace](feature-trace.md#как-использовать) и
[project-todo](project-todo.md#как-использовать).
