# process-compliance-violation-detection

> **Статус: тестовые и непроверенные.** Навыки BAW исключены из основной установки. Полная проверка на IBM BPM/BAW не выполнена; результаты анализаторов требуют сверки с исходниками.

Сопоставить приложение IBM BAW с переданными политиками и требованиями и найти подтверждённые расхождения.

## Использование

```text
Используй $process-compliance-violation-detection: Сравни Claims.twx с приложенной внутренней политикой согласования.
```

## Что учитывать

Для каждого вывода укажи правило и доказательство из артефакта. Встроенные default-rules — проверочные эвристики, а не обязательные нормы. При отсутствии политики предложи техническую оценку, не выдумывай юридические требования.
