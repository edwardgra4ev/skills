# create-baw-widget

> **Статус: тестовые и непроверенные.** Навыки BAW исключены из основной установки. Полная проверка на IBM BPM/BAW не выполнена; результаты анализаторов требуют сверки с исходниками.

Создать или изменить Coach View IBM BAW и собрать локальный TWX toolkit.

## Использование

```text
Используй $create-baw-widget: Создай Coach View для истории согласования и упакуй его в TWX.
```

## Что учитывать

Работай с локальными HTML, CSS, JavaScript и шаблонами. Для упаковки используй рабочую копию навыка в каталоге сборки: upstream-скрипты пишут рядом с собой и меняют конфигурацию. Не запускай их в установленном каталоге. Проверка preview и импорта требует целевой версии Designer.
