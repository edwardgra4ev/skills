# generate-baw-bpmn

> **Статус: тестовые и непроверенные.** Навыки BAW исключены из основной установки. Полная проверка на IBM BPM/BAW не выполнена; результаты анализаторов требуют сверки с исходниками.

Создать BPMN и XSD для импорта в IBM BAW из описания процесса или требований.

## Использование

```text
Используй $generate-baw-bpmn: Создай BPMN процесса согласования отпуска с возвратом на доработку.
```

## Что учитывать

Создавай JSON по references/PROCESS_JSON_SCHEMA.md и запускай scripts/generate_baw_bpmn.py. Проверяй ссылки и ветки локально; успешный импорт в BAW подтверждается только проверкой на стенде.
