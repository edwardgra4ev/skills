# audit-baw-readiness

> **Статус: тестовые и непроверенные.** Навыки BAW исключены из основной установки. Полная проверка на IBM BPM/BAW не выполнена; результаты анализаторов требуют сверки с исходниками.

Оценить контрольные механизмы приложения IBM BAW по TWX и подготовить отчёт о пробелах.

## Использование

```text
Используй $audit-baw-readiness: Оцени готовность Claims.twx к внутреннему аудиту.
```
