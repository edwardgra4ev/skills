# baw-dependency-mapper

> **Статус: тестовые и непроверенные.** Навыки BAW исключены из основной установки. Полная проверка на IBM BPM/BAW не выполнена; результаты анализаторов требуют сверки с исходниками.

Найти использования переменной или Business Object в TWX IBM BAW и оценить влияние изменения.

## Использование

```text
Используй $baw-dependency-mapper: Найди использования ClaimRequest в локальном Claims.twx.
```

## Что учитывать

Запускай scripts/analyze_dependencies.py по выбранному TWX. Различай статические совпадения, подтверждённые связи и предположения о порядке выполнения. Влияние динамических вызовов может остаться непроверенным.
