# create-baw-external-task-ui

> **Статус: тестовые и непроверенные.** Навыки BAW исключены из основной установки. Полная проверка на IBM BPM/BAW не выполнена; результаты анализаторов требуют сверки с исходниками.

Создать внешний интерфейс human task IBM BAW для открытия через Custom URL.

## Использование

```text
Используй $create-baw-external-task-ui: Создай внешнюю форму согласования заявки по схеме входов и выходов задачи.
```

## Что учитывать

Отделяй входы задачи от выходов. Сохраняй task ID и контекст пользователя; завершение реальной задачи является изменением сервера. Создание файлов UI не означает настройку Custom URL или публикацию приложения.
