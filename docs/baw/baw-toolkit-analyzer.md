# baw-toolkit-analyzer

> **Статус: тестовые и непроверенные.** Навыки BAW исключены из основной установки. Полная проверка на IBM BPM/BAW не выполнена; результаты анализаторов требуют сверки с исходниками.

Проанализировать зависимости toolkit, версии и использования артефактов в TWX IBM BAW.

## Использование

```text
Используй $baw-toolkit-analyzer: Покажи зависимости toolkit в Claims.twx и возможные конфликты версий.
```

## Что учитывать

Запускай scripts/analyze_toolkit_deps.py. Отсутствие найденных ссылок не разрешает удаление toolkit. Называй недоступные транзитивные зависимости и границы анализа экспорта.
