# test-baw-service-flows

> **Статус: тестовые и непроверенные.** Навыки BAW исключены из основной установки. Полная проверка на IBM BPM/BAW не выполнена; результаты анализаторов требуют сверки с исходниками.

Подготовить и выполнить тесты Service Flow IBM BAW по его контракту входов и выходов.

## Использование

```text
Используй $test-baw-service-flows: Составь тесты ValidateOrder по переданной схеме без вызова сервиса.
```

## Что учитывать

Сначала проверь контракт. Вызов service flow может менять данные даже при названии Validate или Test. Не подменяй вызов сервиса запуском процесса без согласования; явно разделяй локальную подготовку и проверку на стенде.
