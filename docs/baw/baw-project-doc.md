# baw-project-doc

> **Статус: тестовые и непроверенные.** Навыки BAW исключены из основной установки. Полная проверка на IBM BPM/BAW не выполнена; результаты анализаторов требуют сверки с исходниками.

Документировать приложение IBM BAW по TWX, BPMN и XSD без подключения к серверу.

## Использование

```text
Используй $baw-project-doc: Подготовь техническую документацию по локальному Claims.twx.
```

## Что учитывать

Используй scripts/extract_twx.py для TWX и профильные references для BPMN/XSD. Сверяй извлечённые артефакты с архивом; отсутствие в отчёте не доказывает отсутствие в приложении. Аудитория и путь документа берутся из запроса.
