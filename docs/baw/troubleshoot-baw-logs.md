# troubleshoot-baw-logs

> **Статус: тестовые и непроверенные.** Навыки BAW исключены из основной установки. Полная проверка на IBM BPM/BAW не выполнена; результаты анализаторов требуют сверки с исходниками.

Диагностировать ошибки IBM BAW по SystemOut.log, messages.log, trace.log, FFDC или данным экземпляра.

## Использование

```text
Используй $troubleshoot-baw-logs: Объясни причину ошибки в приложенном фрагменте messages.log.
```

## Что учитывать

Начинай с переданного лога без запроса подключения. Различай ID планировщика и process instance ID; подтверждай связь по BPDInstance, piid или структурированному полю. Рекомендация исправления не разрешает retry или изменение сервера.
