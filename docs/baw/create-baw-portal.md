# create-baw-portal

> **Статус: тестовые и непроверенные.** Навыки BAW исключены из основной установки. Полная проверка на IBM BPM/BAW не выполнена; результаты анализаторов требуют сверки с исходниками.

Разработать портал задач IBM BAW или добавить BAW API в существующее веб-приложение.

## Использование

```text
Используй $create-baw-portal: Добавь список моих задач BAW в существующее приложение.
```

## Что учитывать

Сначала выбери WLE или PFS по окружению. Сохраняй существующий стек. Проверяй авторизацию, пагинацию и контракт ответа; учётные данные сервера не должны попадать в клиентский код.
