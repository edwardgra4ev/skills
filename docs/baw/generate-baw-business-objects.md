# generate-baw-business-objects

> **Статус: тестовые и непроверенные.** Навыки BAW исключены из основной установки. Полная проверка на IBM BPM/BAW не выполнена; результаты анализаторов требуют сверки с исходниками.

Создать или изменить бизнес-объекты IBM BAW в OpenAPI JSON либо упаковать их в TWX.

## Использование

```text
Используй $generate-baw-business-objects: Создай бизнес-объекты Order и OrderItem для импорта в BAW.
```

## Что учитывать

Сохраняй существующие поля, идентификаторы и связи. Отдельно отмечай удаление, переименование и изменение типа. Скрипты scripts/twx-bo-tools работают с локальными архивами; результат ещё нужно импортировать и проверить в BAW.
