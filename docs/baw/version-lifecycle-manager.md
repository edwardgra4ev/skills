# version-lifecycle-manager

> **Статус: тестовые и непроверенные.** Навыки BAW исключены из основной установки. Полная проверка на IBM BPM/BAW не выполнена; результаты анализаторов требуют сверки с исходниками.

Управлять snapshot и переменными окружения IBM BAW по явно выбранной операции.

## Использование

```text
Используй $version-lifecycle-manager: Проверь, что нужно для активации snapshot Claims v2 на тестовом стенде.
```

## Что учитывать

Уточни окружение, container, snapshot и действие. Активация, деактивация, удаление и изменение переменных требуют поручения на конкретную запись. Показ плана и проверка состояния сами по себе такой записи не разрешают.
