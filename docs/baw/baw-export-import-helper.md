# baw-export-import-helper

> **Статус: тестовые и непроверенные.** Навыки BAW исключены из основной установки. Полная проверка на IBM BPM/BAW не выполнена; результаты анализаторов требуют сверки с исходниками.

Перенести приложения и toolkit IBM BAW между окружениями с проверкой зависимостей и порядка импорта.

## Использование

```text
Используй $baw-export-import-helper: Подготовь план переноса Claims и его toolkit с dev на test без импорта.
```

## Что учитывать

Экспорт и анализ порядка можно подготовить отдельно. Импорт, замена версии и изменение зависимостей выполняются только в согласованном окружении. Наличие импортированного snapshot не доказывает его установку или активацию.
