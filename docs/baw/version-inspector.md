# version-inspector

> **Статус: тестовые и непроверенные.** Навыки BAW исключены из основной установки. Полная проверка на IBM BPM/BAW не выполнена; результаты анализаторов требуют сверки с исходниками.

Прочитать метаданные snapshot и версии приложения или toolkit IBM BAW.

## Использование

```text
Используй $version-inspector: Покажи snapshot приложения Claims и его зависимости.
```

## Что учитывать

Только чтение. Проверяй соответствие acronym, ID, branch и snapshot. Наличие версии в authoring не доказывает её развёртывание или активность на runtime.
