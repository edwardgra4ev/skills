# compare-baw-versions

> **Статус: тестовые и непроверенные.** Навыки BAW исключены из основной установки. Полная проверка на IBM BPM/BAW не выполнена; результаты анализаторов требуют сверки с исходниками.

Сравнить два TWX или две версии приложения IBM BAW по процессам, скриптам и настройкам.

## Использование

```text
Используй $compare-baw-versions: Сравни Claims-v1.twx и Claims-v2.twx и покажи изменения скриптов.
```

## Что учитывать

Используй ровно два явно обозначенных источника A и B. Без общего предка различие не доказывает конфликт параллельных правок. Результат — diff и рекомендации; автоматического merge или записи в Designer нет.
