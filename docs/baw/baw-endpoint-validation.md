# baw-endpoint-validation

> **Статус: тестовые и непроверенные.** Навыки BAW исключены из основной установки. Полная проверка на IBM BPM/BAW не выполнена; результаты анализаторов требуют сверки с исходниками.

Проверить TWX IBM BAW на адреса исходного окружения перед переносом на другой сервер.

## Использование

```text
Используй $baw-endpoint-validation: Найди ссылки на старый сервер в Claims.twx по приложенному BPMConfig export.
```

## Что учитывать

Используй scripts/scan_twx_endpoints.py и явно заданные source/target. Наличие oc или kubectl на машине не доказывает тип целевого стенда; отсутствие локальной папки BAW не доказывает CP4BA. Поиск адресов не меняет архив.
