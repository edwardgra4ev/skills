# generate-baw-tests

> **Статус: тестовые и непроверенные.** Навыки BAW исключены из основной установки. Полная проверка на IBM BPM/BAW не выполнена; результаты анализаторов требуют сверки с исходниками.

Подготовить тесты процессов и Coach UI IBM BAW; выполнить согласованные сценарии на тестовом стенде.

## Использование

```text
Используй $generate-baw-tests: Подготовь тестовый набор по Claims.twx без запуска на сервере.
```

## Что учитывать

Разделяй генерацию и выполнение. Создание экземпляров, назначение и завершение задач имеют побочные эффекты. Выполняй только согласованный набор на указанном стенде; без инструментов исполнения выдай тесты и ограничения, а не фиктивный отчёт pass.
