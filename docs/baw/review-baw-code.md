# review-baw-code

> **Статус: тестовые и непроверенные.** Навыки BAW исключены из основной установки. Полная проверка на IBM BPM/BAW не выполнена; результаты анализаторов требуют сверки с исходниками.

Проверить JavaScript, HTML и CSS артефактов IBM BAW из TWX, файлов или переданного кода.

## Использование

```text
Используй $review-baw-code: Проверь серверные скрипты в Claims.twx на ошибки и проблемы производительности.
```

## Что учитывать

Каждое замечание связывай с артефактом, местом и наблюдаемым условием ошибки. Учитывай контекст tw.local и версию JavaScript среды выполнения. Строковый поиск даёт кандидатов, а не доказанные ошибки.
