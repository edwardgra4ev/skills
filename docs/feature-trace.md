# feature-trace

Навык помогает разобраться, как конкретная функция работает по исходному коду:
кто её запускает, откуда приходят данные, какие проверки меняют исход,
что сохраняется и когда появляется наблюдаемый результат.

Подходит для исследования незнакомого механизма, диагностики одного объекта
и оценки влияния изменения API или события на потребителей.

## Подключение

Следуйте [общей инструкции установки](index.md#установка), выбрав
`skills/engineering/feature-trace/`. Обязательных внешних зависимостей нет.

При наличии индекса `.codegraph/` и доступного CodeGraph агент использует
его для цепочек вызовов. Доступную Serena использует для навигации по символам
и поиска ссылок. Для строковых маршрутов, конфигурации и участков, не покрытых
этими инструментами, использует поиск по исходникам. Без CodeGraph и Serena
навык также работает; устанавливать их специально не требуется.

## Как использовать

Укажите функцию или наблюдаемое действие и ожидаемый результат. Если анализ
охватывает несколько репозиториев, предоставьте агенту их расположение и доступ.
Для диагностики полезны обезличенный пример входа и идентификатор объекта.

```text
Используй $feature-trace: проследи обработку заказа от HTTP-запроса до уведомления.
Используй $feature-trace: объясни, как CLI-команда импорта преобразует CSV и сохраняет записи.
Используй $feature-trace: найди потребителей события order.created и оцени изменение его схемы.
Используй $feature-trace: выясни, какие записи и логи доказывают завершение фонового задания.
```

## Что получится

Объяснение связывает вход, преобразования, условия, записи и результат
с конкретными местами реализации. Для сложного преобразования агент добавляет
пример данных; для асинхронного механизма разбирает ошибки, повторы и частичное
выполнение. Порядок диагностики показывает, чем подтвердить каждый этап
и какие сведения невозможно восстановить из сохранённых данных.

Агент отмечает недоступные компоненты и отделяет выводы по исходникам
от проверенного поведения работающего окружения. Анализ контракта сам по себе
не меняет реализацию.

Обычный запрос завершается ответом в чате. Чтобы получить документ, укажите это явно:

```text
Используй $feature-trace: опиши обработку платежа и сохрани результат в docs/payments.md.
```

Документ будет создан в целевом проекте. Правила его размещения и ссылок
берутся из этого проекта.
